## What it does

Opens Agents administration so admins can view roots, register server paths, rescan, and delete agents across owners.

## When to use

Use this when operating a self-hosted SkillForge instance with `SKILLFORGE_AGENT_ROOTS` and you need the admin server-agent workflow.

## Requires

Role admin. Non-admins do not see the menu item; visiting `/admin/agents` shows admin-forbidden.

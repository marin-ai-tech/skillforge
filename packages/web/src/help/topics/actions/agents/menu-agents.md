## What it does

Opens the My agents page from the signed-in user menu so you can list snapshots, add a folder, or delete an agent.

## When to use

Use this control whenever you want the cabinet inventory instead of typing `/me/agents` or using only the CLI scan workflow.

## Requires

Any signed-in role. Anonymous users are sent to sign-in with `next=/me/agents`.

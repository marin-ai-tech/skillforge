## What it does

Downloads the deterministic `.tar.gz` plugin archive for the latest (or selected) version, including `.claude-plugin/plugin.json`.

## When to use

Use when you need the plugin archive itself, for example to inspect it or to install it offline. The archive has the Claude Code plugin layout; to install into your agent, prefer the commands on the Install tab: the marketplace in Claude Code, the SkillForge CLI for every other agent.

## Requires

no sign-in for read when public read is enabled; otherwise viewer+. Promoting to active still requires reviewer+.

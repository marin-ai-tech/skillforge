## What it does

Downloads a zip of canonical version files without plugin.json, useful for inspection or offline packaging.

## When to use

Use when you need the version files themselves, for inspection or offline packaging. To install the artifact into your agent, prefer the commands on the Install tab.

## Requires

no sign-in for read when public read is enabled; otherwise viewer+. Promoting to active still requires reviewer+.

## What it does

Copies or shows `/plugin marketplace add <base>/marketplace.json` so Claude Code can register this SkillForge instance.

## When to use

Use once in Claude Code before installing plugins from this registry; hooks and plugins install only through this marketplace. Other agents install the artifact with the command for their agent further down the Install tab.

## Requires

no sign-in for read when public read is enabled; otherwise viewer+. Promoting to active still requires reviewer+.

## What it does

Copies or shows `/plugin install <plugin>@<marketplace>` for the current active artifact using the server-computed plugin name.

## When to use

Use in Claude Code after adding the marketplace. Claude Code is the only agent with a plugin marketplace, and hooks and plugins install only this way; other agents use the agent selector on the same tab.

## Requires

no sign-in for read when public read is enabled; otherwise viewer+. Promoting to active still requires reviewer+.

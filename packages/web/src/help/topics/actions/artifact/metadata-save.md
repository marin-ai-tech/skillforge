## What it does

Saves the card description, display name, and tags as registry overrides. This does not create a version and does not edit existing version content. You can reset an individual field to the latest version's value.

## When to use

Use this action to correct a public caption or catalog tags while preserving published files and version history. Check the values before saving; the effective card changes immediately.

## Requires

The owner, a maintainer, reviewer, or administrator may save. A regular browser session or API token is required; MCP tokens cannot perform this edit.

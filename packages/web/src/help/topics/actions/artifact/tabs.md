## What it does

Switches among Overview, Files, Versions, Audit, Install, and Quality. The active tab is stored in the tab query parameter so links remain shareable.

## When to use

Use to move between rendered docs, raw files, semver history, and audit events without leaving the artifact page.

## Requires

no sign-in for read when public read is enabled; otherwise viewer+.

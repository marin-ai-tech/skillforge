## What it does

Chooses which immutable semver to display. Defaults to latest_version and updates Overview and Files for that snapshot.

## When to use

Use when comparing older releases, verifying digests, or opening a non-latest version from a shared link with ?version=.

## Requires

no sign-in for read when public read is enabled; otherwise viewer+.

## What it does

Opens `/admin/backups` from the signed-in user menu (`menu-backups`). The item is shown only for the admin role, next to Users administration.

## When to use

Use whenever you need to create or download a registry backup without typing the URL. Viewers and other roles never see this control.

## Requires

Requires sign-in as admin.

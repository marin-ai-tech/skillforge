## What it does

Debounced text filter bound to the q query parameter on /artifacts. Filters cards by name and description without pressing Enter (debounce at most 400 ms).

## When to use

Use to find artifacts quickly from Catalog or after Ctrl/Cmd+K routes you here with a query.

## Requires

no sign-in when public read is enabled; otherwise viewer+.

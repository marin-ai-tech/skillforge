## What it does

Filters catalog results by lifecycle status (candidate, active, aging, zombie, retired) via the status query parameter.

## When to use

Use during review queues (candidate) or ablation passes (aging/zombie) before delete-today decisions.

## Requires

no sign-in when public read is enabled; otherwise viewer+.

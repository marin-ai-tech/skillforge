## What it does

Tabs for all and for each artifact type of the registry, with counts. A count uses every other filter on the page (search, tag, status, team, owner, label, agent). Sets type in the URL and aria-selected on the active tab.

## When to use

Use to restrict browsing to one artifact type before searching or paging.

## Requires

no sign-in when public read is enabled; otherwise viewer+.

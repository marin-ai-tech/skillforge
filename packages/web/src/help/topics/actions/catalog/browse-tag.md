## What it does

Shows the active tag filter with a clear button. Clicking a tag on a card navigates to /artifacts?tag= for that normalized tag.

## When to use

Use to browse related artifacts that share a tag such as workflow.

## Requires

no sign-in when public read is enabled; otherwise viewer+.

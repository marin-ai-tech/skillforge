## What it does

Home chips home-count-<type> show per-type totals and link to /artifacts?type=<type> for skill, command, agent, and hook.

## When to use

Use from Home to jump straight into a typed catalog view without editing the URL by hand.

## Requires

no sign-in when public read is enabled; otherwise viewer+.

## What it does

Shows the Claude Code plugin marketplace block on the home dashboard: the command that adds this registry as a marketplace in Claude Code, and a hint on how other agents install artifacts (the SkillForge CLI, MCP, the Install tab of an artifact).

## When to use

Use once in Claude Code, the only agent with a plugin marketplace, before installing plugins from this registry. For any other agent, open the Install tab of an artifact and pick your agent, or connect the agent over MCP.

## Requires

no sign-in for read when public read is enabled; otherwise viewer+. Promoting to active still requires reviewer+.

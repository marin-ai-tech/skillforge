title: Catalog pagination
summary: Moves between catalog pages of 24 results, keeping the page number in the URL. Use it when results exceed one page or to share a link to the same slice.
related: pages/catalog
---

## What it does

page-prev and page-next controls with a fixed page size of 24. The page index lives in the page query parameter.

## When to use

Use when result sets exceed one page; share URLs that include the page number so others see the same slice.

## Requires

no sign-in when public read is enabled; otherwise viewer+.

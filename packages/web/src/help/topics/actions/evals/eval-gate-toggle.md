---
title: Toggle eval gate
summary: Switches the eval gate of a skill between off and required. Use it so that a weaker version cannot become stable without a passing holdout compare.
related: getting-started/skill-evals, getting-started/eval-runs-runners, getting-started/eval-gate
---

## What it does

Switches gate between off and required. Disabling required needs reviewer or admin; cannot enable without holdout.

## When to use

When consumers must not get a weaker stable without a passing holdout compare.

## Requires

Manage evals to enable; reviewer+ or admin to disable.

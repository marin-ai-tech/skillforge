title: Candidate checkbox

related: pages/import
---

## What it does

Each row of the preview list has a checkbox next to the candidate's type, name, file count and dry-run status (Ready, Warnings, Errors or Conflict). Checked rows are sent to the server when you click Import selected; unchecked rows are not published and do not appear in the results.

## When to use

After Preview, which checks every candidate. Clear the rows you do not want: a row with Errors fails at publish, and a Conflict row is skipped or fails depending on Skip conflicts. Choosing another source or file clears the preview and the selection.

## Requires

Sign-in with contributor or higher and a completed Preview on the Import page. Import selected stays disabled until at least one candidate is checked.

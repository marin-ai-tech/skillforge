## What it does

Sits above the candidate list after Preview. Checking it marks every candidate, including Conflict and Errors rows; clearing it unchecks them all. It shows as checked only while every candidate is selected, so unchecking a single row clears it.

## When to use

Preview already selects all candidates, so use it mainly to clear everything and then check the few rows you want, or to restore the full selection after editing rows by hand.

## Requires

Sign-in with contributor or higher and a completed Preview on the Import page. With nothing selected, Import selected is disabled.

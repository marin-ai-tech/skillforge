## What it does

Chooses how Import loads packages: zip archive, git clone, or local folder. Matching inputs appear for the selected kind.

## When to use

Use zip for plugin archives, git for remote or allowed file URLs, and folder for a directory picked from disk with relative paths.

## Requires

Requires sign-in with contributor or higher to open Import; choosing a source alone does not call the API.

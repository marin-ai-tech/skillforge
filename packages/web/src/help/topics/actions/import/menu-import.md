## What it does

Opens the Import page from the signed-in user menu for contributors and above so bulk zip/git/folder imports are one click away from the catalog.

## When to use

Use when you need to bring in multiple artifacts from a plugin layout or repository instead of publishing a single package.

## Requires

Requires sign-in with contributor, reviewer, or admin. The menu item is hidden for viewers.

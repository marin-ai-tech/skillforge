## What it does

Opens the shared TransitionDialog to retire an artifact listed on the cleanup board, prefilling the reason from data rule codes and metrics.

## When to use

When a zombie row on "Clean up today" should leave recommended use after review.

## Requires

Reviewer or admin. Reuses TransitionDialog; does not invent a separate retire dialog.

## What it does

Opens the admin lifecycle policy page from the account menu. The page shows the policy thresholds and offers a dry run before a confirmed sweep.

## When to use

When you need thresholds, dry-run, or a confirmed policy sweep.

## Requires

Admin role. Reviewers use /lifecycle instead.

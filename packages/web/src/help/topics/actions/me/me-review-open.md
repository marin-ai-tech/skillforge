## What it does

Opens the lifecycle board (`/lifecycle`) from the workspace review section so reviewers and admins can promote or reject candidate artifacts listed in the cabinet overview.

## When to use

Use when `me-review-pending` is greater than zero and you are ready to work the candidate queue with the same promote/reject flows as the lifecycle board.

## Requires

Requires reviewer or admin role. Contributors and viewers do not see the review section or this control on My workspace.

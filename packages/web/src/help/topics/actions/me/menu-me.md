## What it does

Opens `/me` (My workspace) from the first item in the signed-in user menu so you can review your cabinet overview without hunting separate token or agent pages.

## When to use

Use after sign-in when you want a single glance at your artifacts, agents, tokens, activity, and—if eligible—the review queue before browsing the catalog.

## Requires

Requires an active session. Anonymous users cannot open the menu item; navigating to `/me` redirects to login with `next=/me`.

## What it does

Column headers (`metrics-sort-<field>`) reorder the metrics table. Clicking the active column toggles ascending and descending; nulls stay at the end. Sort and order are stored in the URL query.

## When to use

Use to rank by Transfer Rate, Ablation Score, Token Efficiency, Skill Age, sessions, VPR, status, name, or last used before drilling into a card.

## Requires

No special role beyond board visibility. Sorting only reorders artifacts you can already see.

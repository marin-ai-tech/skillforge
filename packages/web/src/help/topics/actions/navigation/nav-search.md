## What it does

Header search field (nav-search). Focus it with Ctrl+K or Cmd/⌘+K; submitting a query routes to /artifacts?q=...

## When to use

Use from any page to jump into Catalog search without opening the Catalog nav item first. Prefer keyboard shortcuts where available (for example Ctrl/Cmd+K for search, ? for page help) before hunting through menus.

## Requires

no sign-in when public read is enabled; otherwise viewer+.

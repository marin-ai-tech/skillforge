## What it does

Cycles light to dark to system. Persists in localStorage key skillforge.theme and sets data-theme on the html element (absent for system).

## When to use

Use to match ambient lighting or to verify UI contrast; system follows prefers-color-scheme.

## Requires

no sign-in.

## What it does

Asks the server for the next page of the feed with the cursor of the current one and appends it under the same day headings. The focus moves to the first new item. If the next page fails, an error with a retry appears in place of the button and retries only that page.

## When to use

Go further back than the first page: after a holiday, or when you look for an older announcement.

## Requires

Nothing beyond reading the feed. The button is shown only while there are older items.

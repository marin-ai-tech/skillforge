## What it does

Form fields for type, name, description, optional version, changelog, model compatibility, and provenance source/ref (human|reckon|agentspace|dreamteam|import).

## When to use

Use to set identity and metadata before submit; leave version blank for autoversion 0.1.0 then patch+1.

## Requires

Requires sign-in with contributor+ to publish.

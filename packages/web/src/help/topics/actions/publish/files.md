## What it does

Stages files for the bundle with hard limits: 32 MiB total, 16 MiB per file, at most 1000 files. Paths are normalized and validated.

## When to use

Use when uploading multi-file skills or hooks that include scripts and README.md.

## Requires

Requires sign-in with contributor+.

## What it does

Opens the help topic for an E_* or W_* code from the Publish issue list so Blocking and Warning guidance is one click away.

## When to use

Use whenever a validation code appears so you can apply the documented fix example and re-validate.

## Requires

Requires sign-in to publish; reading help itself needs no elevated role.

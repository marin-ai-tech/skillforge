## What it does

Paste markdown and frontmatter into an editor to synthesize a single-file artifact without a disk upload.

## When to use

Use for quick command or skill drafts; still must satisfy name (a-z0-9-) and description rules or E_NAME_INVALID / E_DESCRIPTION_* will block.

## Requires

Requires sign-in with contributor+.

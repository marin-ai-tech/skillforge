## What it does

Opens the help topic for a `Q_*` quality code from the Quality tab or Publish quality block so advisory guidance is one click away. Topics live under `codes/<CODE>` using the same mechanism as validation issue help.

## When to use

Use whenever a quality check such as `Q_DESC_SHORT` or `Q_HOOK_NO_TIMEOUT` appears and you need the documented meaning, causes, and fix example before republishing.

## Requires

No elevated role: reading help is available to signed-in and anonymous viewers. Applying the fix and republishing requires contributor or higher.

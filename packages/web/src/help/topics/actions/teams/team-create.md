## What it does

Creates a new team with the given kebab-case name and initial lead username. The lead is added as role lead in the same transaction.

## When to use

Use when a group needs private team-scoped artifacts. Only admins see the create control.

## Requires

Admin role; valid team name; lead must be an existing enabled user.

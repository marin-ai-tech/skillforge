## What it does

Admin creates a user with username, password (min 8), role (viewer|contributor|reviewer|admin), and optional display_name.

## When to use

Use to onboard contributors who need publish, or reviewers for lifecycle gates on candidate artifacts.

## Requires

Requires sign-in as admin.

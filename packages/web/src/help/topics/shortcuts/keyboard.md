SkillForge keeps a small set of global shortcuts so you can open help and search without leaving the keyboard. Shortcuts are ignored while you type in ordinary text inputs so they do not steal characters from forms like Publish or Sign in. The help panel and menus also follow standard dialog focus rules with Escape to dismiss.

| Shortcut | Action |
|---|---|
| `?` (Shift+/) | Toggle the help panel for the current page topic |
| Ctrl+K or ⌘+K (Cmd) | Focus the header catalog search (`nav-search`) |
| Escape or Esc | Close the help panel, open menus, or confirmation dialogs |

After focusing search with Ctrl/Cmd+K, type a query and press Enter to land on `/artifacts?q=...`. Use Escape to dismiss UI chrome, then `?` again if you still need the page topic. These shortcuts work for signed-in and anonymous users whenever the shell is visible. Theme toggle and user menu remain mouse or click targets; they are not assigned additional chords in the MVP.
